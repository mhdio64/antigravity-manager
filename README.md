# Antigravity Manager

[English](README.en.md)

Antigravity Manager یک برنامهٔ گرافیکی برای نصب و مدیریت **Antigravity App** و **Antigravity IDE** روی لینوکس است. این دو محصول جداگانه‌اند و می‌توانی هرکدام را مستقل نصب و به‌روزرسانی کنی.

## چرا این برنامه ساخته شد؟

وقتی Antigravity را به‌صورت فایل فشرده روی لینوکس می‌گیری، برای نصب باید خودت فایل را باز کنی، محل نگهداری‌اش را انتخاب کنی و اگر می‌خواهی برنامه با نام و آیکنش در منوی سیستم پیدا شود، میان‌بر بسازی. برای به‌روزرسانی هم باید نسخهٔ تازه را پیدا و دانلود کنی و جای نسخهٔ فعلی بگذاری. اگر نسخهٔ تازه مشکل داشته باشد، برگشت به نسخهٔ قبلی به این بستگی دارد که فایل‌های آن را نگه داشته باشی.

این مدیر همان کارها را از یک پنجره انجام می‌دهد. مثلاً برای نصب IDE کافی است روی **نصب** در کارت IDE بزنی. مدیر فایل را از منبع رسمی گوگل می‌گیرد، در فضای کاربر فعلی نصب می‌کند و ورودی منو و آیکن را می‌سازد. دفعهٔ بعد می‌توانی از منوی سیستم یا دکمهٔ **اجرا** آن را باز کنی.

## چه کارهایی انجام می‌دهد؟

- **بررسی نسخه:** برای هر محصول وضعیت نصب و به‌روزرسانی را جدا نشان می‌دهد. اگر نسخهٔ نصب‌شده با نسخهٔ موجود در منبع رسمی یکی باشد، پیام **به‌روز است** نمایش داده می‌شود.
- **آپدیت و بازگردانی:** نسخهٔ جدید را آماده می‌کند و برای جابه‌جایی تا بسته‌شدن برنامه صبر می‌کند. یک نسخهٔ قبلی هم برای بازگردانی نگه می‌دارد.
- **حذف:** نسخهٔ فعال، نسخهٔ قبلی و ورودی منوی نصب مدیریت‌شده را حذف می‌کند و تنظیمات و پروژه‌های کاربر را حفظ می‌کند.
- **راست‌چین:** روی نسخه‌های سازگار App و IDE می‌توان نمایش راست‌چین متن را جداگانه فعال یا حذف کرد. این قابلیت به Node.js نسخهٔ 22.12 یا جدیدتر نیاز دارد.

رابط مدیر فارسی و انگلیسی است. ورود به حساب گوگل در خود Antigravity انجام می‌شود و شرایط دسترسی به سرویس را گوگل تعیین می‌کند.

## دانلود و نصب

از [صفحهٔ انتشارها](https://github.com/mhdio64/antigravity-manager/releases) بستهٔ `.deb` مناسب سیستم ۶۴ بیتی Intel یا AMD را بگیر و با نصب‌کنندهٔ بستهٔ سیستم باز کن:

| سیستم | بسته |
| --- | --- |
| Ubuntu یا Kubuntu 26.04 | فایلی که به `_resolute_amd64.deb` ختم می‌شود |
| Ubuntu 24.04 | فایل `_amd64.deb` بدون پسوند `resolute` |

این دو بسته امکانات یکسانی دارند. تفاوتشان در کتابخانه‌های Qt موردنیاز هر نسخهٔ Ubuntu است. ریلیزها فعلاً آزمایشی‌اند و بستهٔ Ubuntu 24.04 برای Linux Mint 22 هنوز در مرحلهٔ آزمایش است.

برای ساخت از سورس، [راهنمای توسعه](prototype/README.md) را بخوان.
